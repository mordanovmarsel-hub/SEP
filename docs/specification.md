# SEP — математическая и функциональная спецификация v1.1

Статус: **утверждённая базовая модель первой итерации + проработанное расширение по Issue #3**  
Источник требований: GitHub Issues #1–#3 и ответы инженера.

> Важно: базовая модель v1 остаётся работоспособной без тепловой коррекции. Модель из раздела 17 добавляется как отдельный расчётный режим и требует дополнительных параметров ФЭП и теплофизических характеристик.

## 1. Назначение

SEP предназначен для поиска **всех допустимых конфигураций солнечной энергетической установки космического аппарата** в заданных ограничениях по мощности, массе, площади и высоте орбиты.

Программа должна:

1. перебрать все допустимые конфигурации;
2. рассчитать мощность, массу и геометрию каждой конфигурации;
3. отфильтровать конфигурации, нарушающие ограничения;
4. показать все допустимые решения;
5. поддержать сортировку и фильтрацию результатов;
6. дополнительно выделять Парето-оптимальные решения;
7. строить 3D-визуализацию результатов.

---

## 2. Входные параметры

### 2.1 Высота орбиты

- обозначение: `H`;
- единицы: км;
- диапазон: `400 <= H <= 3600`;
- первая версия рассматривает постоянную высоту круговой орбиты.

### 2.2 Максимальная масса СЭП

- обозначение: `M_max`;
- единицы: кг;
- ограничение относится ко всей СЭП.

В массу входят:

- ФЭП;
- несущая конструкция;
- концентратор.

### 2.3 Требуемая мощность

- обозначение: `P_required`;
- единицы: Вт;
- допустимое решение должно обеспечивать среднюю мощность не ниже заданной.

### 2.4 Ограничение площади

Пользователь задаёт:

- максимальную площадь одной панели `S_panel_max`, м²;
- количество панелей `N_panel`.

Максимально допустимая суммарная площадь:

```text
S_max = S_panel_max * N_panel
```

## 3. Переменные перебора

### 3.1 Степень концентрации

Для первой версии:

```text
K ∈ {1, 2, 3, 4, 5, 6, 7, 8, 9}
```

Шаг результирующего перебора: `1`.

Опорные значения `K = 1.4` и `K = 2.3` используются только для интерполяции `cos(alpha)` и не являются отдельными результирующими значениями `K` в первой версии.

### 3.2 Тип конструкции

| Тип | Удельная масса конструкции вместе с ФЭП | Допустимый K |
|---|---:|---:|
| Сотопанель | 1.63 кг/м² | `K <= 2.3` |
| Каркас | 1.69 кг/м² | `K <= 9` |

Так как результирующий шаг `K = 1`, для сотопанели фактически допустимы `K = 1` и `K = 2`.

Разницей в массе разных типов ФЭП в первой версии пренебрегаем: она считается одинаковой или несущественной и уже входит в приведённую удельную массу конструкции.

### 3.3 Площадь СЭП

Обозначение: `S_SEP`, м².

Перебор площади:

```text
ΔS = 0.1 м²
```

Диапазон площади ограничивается одновременно:

- `S_SEP <= S_max`;
- максимальной массой;
- минимальной требуемой мощностью.

## 4. Фотоэлектрические преобразователи

Параметры ФЭП задаются в интерфейсе вручную или импортируются из локального CSV. Поддерживается только `.csv`: XLS/XLSX и серверная загрузка не используются. Успешный импорт заменяет текущий список ФЭП; некорректный файл не уничтожает уже введённые данные.

Минимальный формат:

```text
name,efficiencyPercent
```

Допустимы русские заголовки-синонимы: `Название`, `ФЭП`, `КПД`, `КПД %`. КПД в CSV и в форме — проценты (`0 < КПД <= 100`); в ядро по-прежнему уходит доля единицы.

### 4.1 Обязательные параметры базовой модели

- идентификатор/название ФЭП;
- КПД ФЭП при опорных условиях `eta_FEP_ref`, доля единицы.

Различия удельной массы ФЭП отдельно не моделируются.

### 4.2 Дополнительные параметры для модели Issue #3

Для учёта концентрации и температуры желательно поддержать следующие поля:

- `T_ref`, °C — температура, при которой задан `eta_FEP_ref`; по умолчанию 25 °C;
- `gamma_P`, 1/°C — относительный температурный коэффициент максимальной мощности/КПД;
- `eta_vs_K[]` — экспериментальная или паспортная зависимость КПД от степени концентрации при `T_ref`;
- `gamma_P_vs_K[]` — зависимость температурного коэффициента от `K`, если она известна;
- `alpha_solar` — солнечная поглощательная способность поверхности;
- `epsilon_front` — интегральная тепловая эмиссивность лицевой стороны;
- `epsilon_rear` — интегральная тепловая эмиссивность тыльной стороны.

Для физической однодиодной модели дополнительно нужны параметры `I_L`, `I_0`, `R_s`, `R_sh`, коэффициент идеальности `n` и температурные зависимости этих параметров.

## 6. Средний cos(alpha)

### 6.1 Источник модели

Первоначальная формула README вида

```text
cos(alpha) = P0(H) + P1(H)/K + P2(H)/K²
```

**не используется**, поскольку с записанными коэффициентами она не воспроизводит инженерные эталонные значения.

Источник истины — 35 расчётных точек инженера и согласованный в Issue #2 способ интерполяции.

Мы не вводим новую физическую модель `cos(alpha)`. Программа только восстанавливает значение между предоставленными расчётными точками.

### 6.2 Опорная таблица

| H, км | K=1 | K=1.4 | K=2.3 | K=4 | K=9 |
|---:|---:|---:|---:|---:|---:|
| 400 | 0.6630 | 0.6470 | 0.6380 | 0.6329 | 0.6320 |
| 500 | 0.6590 | 0.6473 | 0.6353 | 0.6297 | 0.6286 |
| 800 | 0.7084 | 0.6789 | 0.6622 | 0.6550 | 0.6538 |
| 1600 | 0.7729 | 0.7216 | 0.6985 | 0.6869 | 0.6842 |
| 2000 | 0.7453 | 0.6946 | 0.6728 | 0.6622 | 0.6608 |
| 2800 | 0.6592 | 0.5999 | 0.5737 | 0.5648 | 0.5640 |
| 3600 | 0.6050 | 0.5400 | 0.5200 | 0.5110 | 0.5100 |

### 6.3 Этап 1 — интерполяция по высоте

Для каждого опорного `K_j` строится полином степени не выше 6 через семь точек по высоте.

Формула Лагранжа:

```text
C_j(H) = Σ(i=0..6) C_ij * L_i(H)

L_i(H) = Π(m=0..6, m!=i) (H - H_m) / (H_i - H_m)
```

где:

```text
H_i = [400, 500, 800, 1600, 2000, 2800, 3600]
```

Для реализации рекомендуется барицентрическая форма полинома Лагранжа: это тот же интерполяционный полином, но без необходимости вручную использовать большие коэффициенты.

### 6.4 Этап 2 — линейная интерполяция по K

Для соседних опорных значений `K_L <= K <= K_R`:

```text
cos(alpha, H, K) =
    C_L(H)
    + (K - K_L) / (K_R - K_L) * (C_R(H) - C_L(H))
```

Для результирующих целых `K`:

```text
K=1: C_1
K=2: C_1.4 + (2/3) * (C_2.3 - C_1.4)
K=3: C_2.3 + (7/17) * (C_4 - C_2.3)
K=4: C_4
K=5: C_4 + 0.2 * (C_9 - C_4)
K=6: C_4 + 0.4 * (C_9 - C_4)
K=7: C_4 + 0.6 * (C_9 - C_4)
K=8: C_4 + 0.8 * (C_9 - C_4)
K=9: C_9
```

Интерполяция разрешена только в области:

```text
400 <= H <= 3600
1 <= K <= 9
```

Экстраполяция запрещена.

### 6.5 Источник математических формул

- полином Лагранжа — стандартная формула интерполяции по набору известных точек;
- барицентрическая форма — вычислительно устойчивый способ вычислить тот же полином;
- линейная интерполяция по `K` — уравнение прямой между двумя соседними опорными значениями и согласованный в Issue #1/#2 способ расчёта.

## 7. Модель мощности

### 7.1 Базовая модель v1

```text
q_sol = 1361 Вт/м²
```

Оптический КПД:

```text
eta_opt(K) = 1.00, если K = 1
eta_opt(K) = 0.99, если K > 1
```

Средняя электрическая мощность:

```text
P_avg = q_sol * S_FEP * K * eta_FEP_ref * eta_opt(K) * cos(alpha)
```

или с учётом `S_FEP * K = S_SEP`:

```text
P_avg = q_sol * S_SEP * eta_FEP_ref * eta_opt(K) * cos(alpha)
```

### 7.2 Расширенная модель Issue #3

При включённом учёте концентрации и температуры вместо постоянного `eta_FEP_ref` используется эффективный КПД:

```text
P_avg = q_sol * S_FEP * K * eta_opt(K) * cos(alpha) * eta_FEP_eff(K, T_cell)
```

Модель `eta_FEP_eff` описана в разделе 17.

## 8. Концентратор

- при `K > 1` площадь концентратора принимается равной `S_SEP`;
- средняя толщина линзы: `t = 2 мм = 0.002 м`;
- `eta_opt = 0.99` при `K > 1`;
- для `K = 1` концентратора нет, `eta_opt = 1`, масса концентратора равна нулю.

### 8.1 Удельная масса концентратора

```text
sigma_concentrator [кг/м²] = 2 * rho [г/см³]
```

или в СИ:

```text
sigma_concentrator = rho_kg_m3 * 0.002
```

### 8.2 Рабочая таблица материалов

| Материал | rho, г/см³ | sigma при 2 мм, кг/м² |
|---|---:|---:|
| CaF2 | 3.18 | 6.360 |
| MgF2 | 3.177 | 6.354 |
| BK7 | 2.50 | 5.000 |
| Синтетическое стекло UV | 2.202 | 4.404 |
| Кварцевое стекло | 2.649 | 5.298 |

Для научной/промышленной версии значения плотности и фактической толщины должны быть привязаны к проверенному источнику данных.

## 9. Модель массы

Для `K = 1`:

```text
M_concentrator = 0
M_total = M_structure
```

Для `K > 1`:

```text
M_structure = sigma_structure * S_SEP
M_concentrator = sigma_concentrator * S_SEP
M_total = M_structure + M_concentrator
```

где:

- `sigma_structure = 1.63 кг/м²` для сотопанели;
- `sigma_structure = 1.69 кг/м²` для каркаса.

## 11. Алгоритм полного перебора

Для выбранной высоты `H`:

1. загрузить список ФЭП;
2. для каждого ФЭП загрузить параметры выбранной модели КПД;
3. перебрать тип конструкции;
4. перебрать материал концентратора для `K > 1`;
5. перебрать `K = 1..9`;
6. исключить `K`, недопустимые для конструкции;
7. вычислить `cos(alpha)`;
8. вычислить `eta_opt`;
9. перебрать `S_SEP` с шагом `0.1 м²`;
10. вычислить `S_FEP = S_SEP / K`;
11. если тепловая модель выключена — использовать `eta_FEP_ref`;
12. если тепловая модель включена — вычислить `T_cell` и `eta_FEP_eff(K,T_cell)` итерационно;
13. вычислить мощность;
14. вычислить массу;
15. применить ограничения;
16. сохранить допустимое решение.

Для `K = 1` материал концентратора не включается.

Проверить:

- при отсутствии параметров расширенной модели приложение корректно возвращается к базовой модели.

## 17. Расширение Issue #3: влияние концентрации и температуры на КПД ФЭП

### 17.1 Цель

Концентрация света имеет два противоположных эффекта:

1. при умеренной концентрации КПД солнечного элемента может увеличиваться вследствие роста напряжения холостого хода;
2. концентрация увеличивает тепловую нагрузку, рост температуры обычно уменьшает напряжение и максимальную мощность.

Эти эффекты связаны между собой, поэтому корректная модель должна определять КПД и рабочую температуру совместно.

### 17.2 Почему нельзя задать универсальную поправку только от K

Не существует универсального коэффициента вида `+X% КПД на каждый K`.

Зависимость определяется технологией ФЭП, последовательным сопротивлением, токами рекомбинации, коэффициентом идеальности, тепловым режимом и конструкцией отвода тепла. При больших концентрациях потери на последовательном сопротивлении могут остановить рост КПД и привести к его уменьшению.

Поэтому для SEP предусмотрены два уровня модели.

### 17.3 Уровень A — рекомендуемая эмпирическая модель

Это предпочтительный вариант для первой реализации Issue #3, если инженер/производитель может предоставить паспортные или экспериментальные данные.

#### Поправка на концентрацию

Для каждого ФЭП задаётся таблица КПД при опорной температуре:

```text
eta_vs_K = [
  { K: 1, eta: ... },
  { K: 2, eta: ... },
  ...
]
```

Значение между опорными точками определяется кусочно-линейной интерполяцией.

Определим:

```text
F_conc(K) = eta_at_K(T_ref) / eta_FEP_ref
```

Если таблицы `eta_vs_K` нет, в первой версии:

```text
F_conc(K) = 1
```

То есть программа **не придумывает** увеличение КПД.

#### Поправка на температуру

Стандартная линейная модель температурной коррекции максимальной мощности:

```text
F_temp(K,T) = 1 + gamma_P(K) * (T_cell - T_ref)
```

и

```text
eta_FEP_eff(K,T) = eta_FEP_ref * F_conc(K) * F_temp(K,T)
```

где `gamma_P` задаётся в `1/°C`. Для типичного ФЭП он отрицательный.

Если зависимость `gamma_P(K)` неизвестна, допускается использовать постоянный паспортный `gamma_P`, но результат должен быть помечен как приближённый.

### 17.4 Уровень B — физическая однодиодная модель

Для более точного режима КПД не задаётся отдельной поправкой, а рассчитывается из I–V характеристики элемента.

Базовое уравнение:

```text
I = I_L
    - I_0 * ( exp((V + I*R_s)/(n*V_T)) - 1 )
    - (V + I*R_s)/R_sh
```

где:

```text
V_T = k_B * T / q
```

а фототок `I_L` приблизительно пропорционален интенсивности света, то есть концентрации `K`.

Рост интенсивности приводит к логарифмическому росту `V_oc`, тогда как потери `I²R_s` растут с током. Эта модель поэтому может естественно воспроизвести и рост КПД при умеренном `K`, и его спад при чрезмерной концентрации.

Для неё нужны параметры конкретного ФЭП, поэтому она не должна включаться без достоверных данных.

### 17.5 Тепловая модель для космоса

Наземные PV-модели температуры, использующие температуру воздуха и скорость ветра, для космического аппарата напрямую неприменимы.

В вакууме основной механизм отвода тепла — излучение.

Поток на ФЭП в упрощённой модели:

```text
G_cell = q_sol * K * eta_opt(K) * cos(alpha)
```

Упрощённый стационарный радиационный баланс:

```text
(alpha_solar - eta_FEP_eff) * G_cell + q_env
    = (epsilon_front + epsilon_rear) * sigma_SB * T_cell^4
      + q_conduction
```

где:

- `alpha_solar` — доля солнечной энергии, поглощаемой ФЭП;
- `sigma_SB = 5.670374419e-8 W/(m²*K⁴)` — постоянная Стефана–Больцмана;
- `q_env` — дополнительный внешний тепловой поток, например ИК-излучение Земли и альбедо;
- `q_conduction` — отвод тепла проводимостью в конструкцию/радиатор;
- `T_cell` — температура в K.

Для упрощённой автономной панели, если временно принять `q_env = 0` и `q_conduction = 0`:

```text
T_cell = [
  ((alpha_solar - eta_FEP_eff) * G_cell)
  / ((epsilon_front + epsilon_rear) * sigma_SB)
]^(1/4)
```

Это уравнение не является полностью явным, потому что `eta_FEP_eff` само зависит от `T_cell`.

### 17.6 Итерационное решение

Рекомендуемый алгоритм:

```text
T = T_ref

repeat:
    eta = calculate_eta(K, T)
    T_new = solve_radiative_balance(K, eta)

until abs(T_new - T) < tolerance
```

Рекомендуемые технические параметры:

```text
tolerance = 0.01 K
max_iterations = 100
```

При отсутствии сходимости конфигурация должна получать диагностический статус, а не молча возвращать неверный результат.

### 17.7 Что необходимо получить от инженера/из таблицы ФЭП

Минимально для эмпирической модели:

1. `eta_FEP_ref`;
2. `T_ref`;
3. `gamma_P`;
4. желательно — `eta_vs_K` для `K=1..9` или нескольких опорных K;
5. `alpha_solar`;
6. `epsilon_front`;
7. `epsilon_rear`.

Для полноценного теплового баланса дополнительно:

8. учитывать ли теплопроводность в несущую конструкцию/радиатор;
9. учитывать ли ИК-поток и альбедо Земли;
10. есть ли допустимые пределы температуры конкретного ФЭП.

Для однодиодной модели нужны электрические параметры конкретных элементов.

### 17.8 Режимы приложения

Предусмотреть два режима:

```text
EFFICIENCY_MODEL = CONSTANT
```

Использует прежнюю базовую модель v1.

```text
EFFICIENCY_MODEL = THERMAL_CONCENTRATION
```

Использует совместную модель `K -> T_cell -> eta_FEP_eff`.

Это позволяет внедрить Issue #3 без изменения результатов уже утверждённой базовой модели.

## 18. Границы и статус моделей

### 18.1 Утверждённая базовая модель

Базовая v1 полностью определена и может быть реализована сейчас:

- постоянный КПД ФЭП;
- согласованная интерполяция `cos(alpha)`;
- `K=1..9`;
- постоянный `eta_opt`;
- текущая модель массы и площади.

### 18.2 Расширение Issue #3

Математическая архитектура проработана, но реальные расчёты нельзя считать утверждёнными до появления параметров конкретных ФЭП:

- температурного коэффициента;
- данных КПД при концентрации либо параметров однодиодной модели;
- поглощательной способности и эмиссивности;
- инженерного решения по учёту альбедо/ИК Земли и теплопроводности.

До получения этих данных режим `THERMAL_CONCENTRATION` должен считаться **экспериментальным/отключённым по умолчанию**.

По-прежнему вне текущей модели:

- деградация от радиации и времени;
- спектральная модель концентратора;
- изменение толщины линзы от геометрии;
- стоимость;
- некруговые орбиты;
- `H` вне 400–3600 км;
- `K > 9`.
