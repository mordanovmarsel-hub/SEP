# SEP — математическая и функциональная спецификация v1

Статус: **утверждённая модель для первой итерации**  
Источник требований: обсуждение GitHub Issue #1 и ответы инженера.  

## 1. Назначение

SEP предназначен для поиска **всех допустимых конфигураций солнечной энергетической установки космического аппарата** в заданных ограничениях по мощности, массе, площади и высоте орбиты.

Программа должна:

1. перебрать все допустимые конфигурации;
2. рассчитать мощность, массу и геометрию каждой конфигурации;
3. отфильтровать конфигурации, нарушающие ограничения;
4. показать все допустимые решения;
5. поддержать сортировку и фильтрацию результатов;
6. дополнительно выделять Парето-оптимальные решения;
7. строить 3D-визуализацию результатов.

---

## 2. Входные параметры

### 2.1 Высота орбиты

- обозначение: `H`;
- единицы: км;
- диапазон: `400 <= H <= 3600`;
- первая версия рассматривает постоянную высоту круговой орбиты.

### 2.2 Максимальная масса СЭП

- обозначение: `M_max`;
- единицы: кг;
- ограничение относится ко всей СЭП.

В массу входят:

- ФЭП;
- несущая конструкция;
- концентратор.

### 2.3 Требуемая мощность

- обозначение: `P_required`;
- единицы: Вт;
- допустимое решение должно обеспечивать среднюю мощность не ниже заданной.

### 2.4 Ограничение площади

Пользователь задаёт:

- максимальную площадь одной панели `S_panel_max`, м²;
- количество панелей `N_panel`.

Максимально допустимая суммарная площадь:

```text
S_max = S_panel_max * N_panel
```

---

## 3. Переменные перебора

### 3.1 Степень концентрации

Для первой версии:

```text
K ∈ {1, 2, 3, 4, 5, 6, 7, 8, 9}
```

Шаг результирующего перебора: `1`.

Опорные значения `K = 1.4` и `K = 2.3` используются только для интерполяции `cos(alpha)` и не являются отдельными результирующими значениями `K` в первой версии.

### 3.2 Тип конструкции

| Тип | Удельная масса конструкции вместе с ФЭП | Допустимый K |
|---|---:|---:|
| Сотопанель | 1.63 кг/м² | `K <= 2.3` |
| Каркас | 1.69 кг/м² | `K <= 9` |

Так как результирующий шаг `K = 1`, для сотопанели в первой версии фактически допустимы `K = 1` и `K = 2`.

Разницей в массе разных типов ФЭП в первой версии пренебрегаем: она считается одинаковой или несущественной и уже входит в приведённую удельную массу конструкции.

### 3.3 Площадь СЭП

Обозначение: `S_SEP`, м².

Перебор площади выполняется с шагом:

```text
ΔS = 0.1 м²
```

Диапазон площади ограничивается одновременно:

- `S_SEP <= S_max`;
- ограничением максимальной массы;
- требованием минимальной мощности.

---

## 4. Фотоэлектрические преобразователи

Параметры ФЭП загружаются из внешней таблицы.

Для расчётного ядра первой версии обязательно требуется:

- идентификатор/название ФЭП;
- КПД ФЭП `eta_FEP` в долях единицы.

Различия удельной массы ФЭП отдельно не моделируются.

---

## 5. Связь площадей

Площадь ФЭП:

```text
S_FEP = S_SEP / K
```

или эквивалентно:

```text
S_FEP * K = S_SEP
```

## 6. Средний cos(alpha)

### 6.1 Важное изменение относительно первоначального README

Старая формула вида

```text
cos(alpha) = P0(H) + P1(H)/K + P2(H)/K²
```

**не используется**: она не воспроизводит инженерные эталонные значения.

Источником истины для первой версии является таблица опорных значений ниже и двухэтапная интерполяция:

1. полиномиальная интерполяция 6-й степени по высоте `H` отдельно для каждого опорного `K`;
2. линейная интерполяция по `K` между соседними опорными значениями.

### 6.2 Опорная таблица

| H, км | K=1 | K=1.4 | K=2.3 | K=4 | K=9 |
|---:|---:|---:|---:|---:|---:|
| 400 | 0.6630 | 0.6470 | 0.6380 | 0.6329 | 0.6320 |
| 500 | 0.6590 | 0.6473 | 0.6353 | 0.6297 | 0.6286 |
| 800 | 0.7084 | 0.6789 | 0.6622 | 0.6550 | 0.6538 |
| 1600 | 0.7729 | 0.7216 | 0.6985 | 0.6869 | 0.6842 |
| 2000 | 0.7453 | 0.6946 | 0.6728 | 0.6622 | 0.6608 |
| 2800 | 0.6592 | 0.5999 | 0.5737 | 0.5648 | 0.5640 |
| 3600 | 0.6050 | 0.5400 | 0.5200 | 0.5110 | 0.5100 |

### 6.3 Каноническая формула интерполяции по высоте

Для каждого опорного `K_j` строится единственный полином степени не выше 6, проходящий через семь точек `(H_i, C_ij)`.

Рекомендуемая математическая запись — полином Лагранжа:

```text
C_j(H) = Σ(i=0..6) C_ij * L_i(H)

L_i(H) = Π(m=0..6, m!=i) (H - H_m) / (H_i - H_m)
```

где:

```text
H_i = [400, 500, 800, 1600, 2000, 2800, 3600]
```

а `C_ij` — значения `cos(alpha)` из таблицы для соответствующего `K_j`.

Для численной реализации рекомендуется **барицентрическая форма интерполяции Лагранжа**, так как она численно устойчивее прямого вычисления коэффициентов полинома.

### 6.4 Эквивалентная нормированная полиномиальная форма

Для проверки и прозрачности можно использовать нормированную переменную:

```text
x = (H - 2000) / 1600
```

Тогда для каждого опорного `K`:

```text
C_K(H) = a0 + a1*x + a2*x² + a3*x³ + a4*x⁴ + a5*x⁵ + a6*x⁶
```

Коэффициенты:

| K | a0 | a1 | a2 | a3 | a4 | a5 | a6 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 1 | 0.7453 | -0.121229147253 | -0.002612395605 | 0.017971900856 | -0.590957017824 | 0.074257246397 | 0.482269413429 |
| 1.4 | 0.6946 | -0.142877988501 | -0.105021548970 | 0.094675197011 | -0.186362764167 | -0.005297208511 | 0.190284313137 |
| 2.3 | 0.6728 | -0.133013211660 | -0.101107530929 | 0.018312245274 | -0.244488052636 | 0.055700966386 | 0.251795583566 |
| 4 | 0.6622 | -0.124807630401 | -0.090924006100 | -0.016292150315 | -0.271869364857 | 0.080149780716 | 0.272543370957 |
| 9 | 0.6608 | -0.116521027304 | -0.084945011647 | -0.050774446124 | -0.302982443145 | 0.106295473428 | 0.298127454792 |

Эти полиномы воспроизводят все 35 исходных опорных значений с машинной точностью при использовании полных коэффициентов.

### 6.5 Линейная интерполяция по K

После вычисления `C_K(H)` для опорных значений `K = [1, 1.4, 2.3, 4, 9]` значение для промежуточного `K` вычисляется линейно.

Для соседних опорных значений `K_L <= K <= K_R`:

```text
cos(alpha, H, K) = C_L(H) + (K - K_L)/(K_R - K_L) * (C_R(H) - C_L(H))
```

Для результирующих целых `K` первой версии это эквивалентно:

```text
K=1: C_1
K=2: C_1.4 + (2/3) * (C_2.3 - C_1.4)
K=3: C_2.3 + (7/17) * (C_4 - C_2.3)
K=4: C_4
K=5: C_4 + 0.2 * (C_9 - C_4)
K=6: C_4 + 0.4 * (C_9 - C_4)
K=7: C_4 + 0.6 * (C_9 - C_4)
K=8: C_4 + 0.8 * (C_9 - C_4)
K=9: C_9
```

Интерполяция разрешена только в утверждённой области:

```text
400 <= H <= 3600
1 <= K <= 9
```

Экстраполяция за эти пределы в первой версии запрещена.

## 7. Модель мощности

Солнечная плотность потока принимается постоянной:

```text
q_sol = 1361 Вт/м²
```

Оптический КПД концентратора:

```text
eta_opt(K) = 1.00, если K = 1
eta_opt(K) = 0.99, если K > 1
```

Средняя электрическая мощность:

```text
P_avg = q_sol * S_FEP * K * eta_FEP * eta_opt(K) * cos(alpha)
```

С учётом `S_FEP * K = S_SEP`:

```text
P_avg = q_sol * S_SEP * eta_FEP * eta_opt(K) * cos(alpha)
```

В первой версии не учитываются:

- изменение КПД ФЭП при концентрации;
- температурное изменение КПД;
- электрические потери;
- деградация ФЭП во времени;
- зависимость оптического КПД от материала или длины волны.

---

## 8. Концентратор

Для первой версии:

- площадь концентратора при `K > 1` принимается равной `S_SEP`;
- средняя толщина линзы принимается постоянной: `t = 2 мм = 0.002 м`;
- оптический КПД при `K > 1`: `0.99`;
- КПД не зависит от материала, температуры и длины волны.

Для `K = 1` концентрация отсутствует: в расчётной модели принимается `eta_opt = 1` и масса концентратора равна нулю.

### 8.1 Удельная масса концентратора

Если плотность материала задана в `г/см³`, то при толщине 2 мм:

```text
sigma_concentrator [кг/м²] = 2 * rho [г/см³]
```

Общая формула:

```text
sigma_concentrator = rho_kg_m3 * 0.002
```

### 8.2 Рабочая таблица материалов

В первой версии используются плотности из исходной инженерной таблицы с исправлением BK7.

| Материал | rho, г/см³ | sigma при 2 мм, кг/м² |
|---|---:|---:|
| CaF2 | 3.18 | 6.360 |
| MgF2 | 3.177 | 6.354 |
| BK7 | 2.50 | 5.000 |
| Синтетическое стекло UV | 2.202 | 4.404 |
| Кварцевое стекло | 2.649 | 5.298 |

Примечание: для промышленной/научной версии значения плотности и фактической толщины должны быть привязаны к проверенному источнику данных. Для MVP используются приведённые инженерные допущения.

## 9. Модель массы

Для `K = 1`:

```text
M_concentrator = 0
M_total = M_structure
```

Для `K > 1`:

```text
M_structure = sigma_structure * S_SEP
M_concentrator = sigma_concentrator * S_SEP
M_total = M_structure + M_concentrator
```

где:

- `sigma_structure = 1.63 кг/м²` для сотопанели;
- `sigma_structure = 1.69 кг/м²` для каркаса.

---

## 10. Условия допустимости решения

Конфигурация считается допустимой, если одновременно выполняются все условия:

```text
P_avg >= P_required
M_total <= M_max
S_SEP <= S_max
400 <= H <= 3600
1 <= K <= 9
```

и конструктивное ограничение:

```text
сотопанель: K <= 2.3
каркас: K <= 9
```

Дополнительно все входные данные должны быть положительными и иметь корректные единицы измерения.

---

## 11. Алгоритм полного перебора

Для выбранной высоты `H`:

1. загрузить список ФЭП;
2. для каждого ФЭП взять `eta_FEP`;
3. перебрать тип конструкции;
4. перебрать материал концентратора для `K > 1`;
5. перебрать `K = 1..9` с шагом 1;
6. исключить `K`, недопустимые для конструкции;
7. вычислить `cos(alpha)` через интерполяцию;
8. вычислить `eta_opt`;
9. перебрать `S_SEP` с шагом `0.1 м²` в допустимом диапазоне;
10. вычислить `S_FEP = S_SEP / K`;
11. вычислить мощность;
12. вычислить массу;
13. применить ограничения;
14. сохранить допустимое решение.

Для `K = 1` материал концентратора в комбинацию не включается.

---

## 12. Результат одной конфигурации

Для каждого допустимого решения сохраняются как минимум:

- тип ФЭП;
- тип конструкции;
- материал концентратора (`null` при `K=1`);
- `H`;
- `K`;
- `cos(alpha)`;
- `S_SEP`;
- `S_FEP`;
- `P_avg`;
- `M_total`;
- удельная мощность `P_avg / M_total`, Вт/кг;
- запас по мощности `P_avg - P_required`;
- запас по массе `M_max - M_total`.

---

## 13. Фильтрация и сортировка

Пользователь должен иметь возможность фильтровать минимум по:

- ФЭП;
- конструкции;
- материалу концентратора;
- `K`;
- диапазону площади;
- диапазону мощности;
- диапазону массы;
- признаку `Pareto = true/false`.

Сортировка должна поддерживаться по числовым полям в обе стороны.

---

## 14. Многокритериальная оптимизация / множество Парето

Полный список допустимых решений является первичным результатом. Парето-фильтрация является дополнительным способом выделения инженерно интересных решений.

Для MVP рекомендуется использовать следующие цели:

- минимизировать `M_total`;
- минимизировать `S_FEP`;
- максимизировать удельную мощность `P_avg / M_total`.

Решение `A` доминирует решение `B`, если `A` не хуже `B` по всем выбранным критериям и строго лучше хотя бы по одному.

Все недоминируемые решения получают признак:

```text
is_pareto = true
```

Набор критериев желательно оставить конфигурируемым, чтобы позднее можно было добавлять/убирать `S_SEP`, `P_avg`, стоимость и другие параметры без изменения расчётного ядра.

## 16. Тестирование

### 16.1 Интерполяция

Обязательный regression test: для всех 35 опорных комбинаций `(H, K)` вычисленный `cos(alpha)` должен совпадать с таблицей в пределах выбранной численной погрешности, например:

```text
abs(actual - expected) <= 1e-6
```

Также проверить:

- `K=2` как интерполяцию между `1.4` и `2.3`;
- `K=3` между `2.3` и `4`;
- `K=5..8` между `4` и `9`;
- запрет экстраполяции для `H < 400`, `H > 3600`, `K < 1`, `K > 9`.

### 16.2 Мощность

Проверить отдельно случаи:

- `K=1`, где `eta_opt=1`;
- `K>1`, где `eta_opt=0.99`.

### 16.3 Масса

Проверить:

- отсутствие массы концентратора при `K=1`;
- правильный пересчёт `rho -> кг/м²` при толщине 2 мм;
- ограничения по массе;
- ограничения конструкции по `K`.

### 16.4 Полный перебор

Для тестового набора входов проверить, что:

- недопустимые конфигурации отбрасываются;
- все допустимые конфигурации присутствуют;
- дубликаты отсутствуют;
- вычисление Pareto-флага детерминировано.

## 17. Границы первой версии

В MVP сознательно не входят:

- тепловая модель ФЭП;
- изменение КПД ФЭП в зависимости от концентрации;
- деградация;
- электрические потери;
- спектральная модель концентратора;
- изменение толщины линзы в зависимости от материала/геометрии;
- стоимость;
- некруговые орбиты;
- высоты вне диапазона 400–3600 км;
- `K > 9`.

Эти параметры должны добавляться как расширения модели, не ломая базовое расчётное ядро.
