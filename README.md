# SEP

SEP — программа для поиска допустимых конфигураций солнечной энергетической установки космического аппарата с учётом ограничений по мощности, массе, площади, высоте орбиты, типу конструкции и степени концентрации.

## Документация

Источники истины для реализации:

- [`docs/specification.md`](docs/specification.md) — математическая и функциональная спецификация;
- [`docs/architecture.md`](docs/architecture.md) — архитектура MVP и технологический стек.

## Разработка

Требования: Node.js 22+, pnpm 10 (`corepack enable`).

```bash
pnpm install
pnpm dev        # Vite + React, apps/web
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Структура workspace:

- `apps/web` — клиент на Vite + React;
- `packages/core` — математическое ядро `@sep/core`;
- `packages/tsconfig` — общие TypeScript-конфиги.

Клиент импортирует `@sep/core` и выполняет расчёты локально в браузере. Backend-приложения нет. Статический production build публикуется в GitHub Pages из `apps/web/dist`.

## Архитектура MVP

- Turborepo + `pnpm` workspaces;
- TypeScript;
- отдельная библиотека `@sep/core` для всей математической и предметной логики;
- Vitest для unit/regression tests;
- Vite + React для клиентского приложения;
- серверное приложение отсутствует;
- расчёты выполняются локально в браузере;
- GitHub Actions — CI/CD;
- статический deploy клиента после успешных тестов и build.

## Основные параметры MVP

- высота круговой орбиты: `400–3600 км`;
- степень концентрации: `K = 1..9`, шаг `1`;
- площадь СЭП: шаг перебора `0.1 м²`;
- конструкции:
  - сотопанель — `1.63 кг/м²`, `K <= 2.3`;
  - каркас — `1.69 кг/м²`, `K <= 9`;
- солнечная плотность потока: `1361 Вт/м²`;
- оптический КПД:
  - `1.00` при `K = 1`;
  - `0.99` при `K > 1`.

## Расчёт среднего cos(alpha)

Первоначальная аналитическая формула из ранней версии README признана некорректной и больше не используется.

В актуальной модели `cos(alpha)` рассчитывается по инженерным опорным значениям:

1. полиномиальная интерполяция 6-й степени по высоте на 7 опорных точках;
2. линейная интерполяция по степени концентрации `K`.

Подробности приведены в [`docs/specification.md`](docs/specification.md#6-средний-cosalpha).

## Результат

Программа должна выдавать все допустимые конфигурации, поддерживать фильтрацию/сортировку, выделение Парето-оптимальных решений и 3D-визуализацию результатов.
