# SEP

SEP — программа для поиска **всех допустимых конфигураций** солнечной энергетической установки космического аппарата с учётом ограничений по мощности, массе, площади, высоте орбиты, типу конструкции и степени концентрации.

Текущий MVP — полностью клиентское приложение: форма ограничений → перебор в `@sep/core` → таблица, фильтры, сортировка, метки Парето и 3D-график. Backend, авторизация и сохранение расчётов не используются.

## Что делает MVP

Пользователь задаёт высоту орбиты, лимиты по массе/мощности/площади, один или несколько ФЭП (название и КПД в %), конструкции и материалы концентратора, затем нажимает **Рассчитать**.

Программа:

1. перебирает все допустимые конфигурации через `calculateSep()`;
2. отбрасывает решения, нарушающие ограничения;
3. показывает сводку, полный список feasible-решений и Парето-метки;
4. позволяет фильтровать и сортировать уже посчитанные результаты без повторного перебора;
5. строит 3D scatter: мощность / удельная масса / площадь ФЭП.

Справочные материалы концентратора и подписи конструкций («Сотопанель», «Каркас») лежат в `@sep/data`. Каталога готовых ФЭП нет: значения задаёт пользователь, вымышленных инженерных ячеек в репозитории нет.

## Тепловая модель

Режим `THERMAL_CONCENTRATION` / `eta_FEP_eff` **не реализован и отключён**. Базовый MVP использует только `EFFICIENCY_MODEL = CONSTANT` (постоянный КПД ФЭП). Расширенная тепловая модель ждёт дополнительных инженерных данных и не влияет на результаты v1.

## Разработка

Требования: Node.js 22+, pnpm 10 (`corepack enable`).

```bash
pnpm install
pnpm dev                 # Vite + React, apps/web
pnpm --filter @sep/web dev
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm --filter @sep/web build
```

Структура workspace:

- `apps/web` — клиент на Vite + React (`@sep/web`);
- `packages/core` — математическое ядро `@sep/core`;
- `packages/data` — справочники `@sep/data` (материалы концентратора, подписи конструкций);
- `packages/tsconfig` — общие TypeScript-конфиги.

Клиент импортирует `@sep/core` и `@sep/data` и выполняет расчёты локально в браузере. Статический production build публикуется в GitHub Pages из `apps/web/dist`.

## Пример `calculateSep()`

КПД в ядре — доля единицы. В UI пользователь вводит проценты, конверсия `% → fraction` происходит только в `apps/web`. В примере ниже `efficiency: 0.3` — произвольное пользовательское значение (30%), не каталожный и не справочный ФЭП.

```ts
import { calculateSep } from '@sep/core';
import { CONCENTRATOR_MATERIALS } from '@sep/data';

const result = calculateSep({
  altitudeKm: 800,
  maxMassKg: 20,
  requiredPowerW: 20,
  maxPanelAreaM2: 0.3,
  panelCount: 1,
  photovoltaicCells: [{ id: 'user-1', name: 'ФЭП 1', efficiency: 0.3 }],
  structures: ['honeycomb', 'frame'],
  concentratorMaterials: [...CONCENTRATOR_MATERIALS],
});

// result.solutions, result.totalGenerated, result.totalFeasible
```

## Архитектура MVP

- Turborepo + `pnpm` workspaces;
- TypeScript;
- отдельная библиотека `@sep/core` для всей математической и предметной логики;
- `@sep/data` для утверждённых справочников, без зависимости ядра от data;
- Vitest для unit/regression tests;
- Vite + React для клиентского приложения;
- Plotly только в `apps/web`;
- серверное приложение отсутствует;
- расчёты выполняются локально в браузере;
- GitHub Actions — CI/CD;
- статический deploy клиента после успешных тестов и build.

## Основные параметры MVP

- высота круговой орбиты: `400–3600 км`;
- степень концентрации: `K = 1..9`, шаг `1`;
- площадь СЭП: шаг перебора `0.1 м²`;
- конструкции:
  - сотопанель — `1.63 кг/м²`, `K <= 2.3`;
  - каркас — `1.69 кг/м²`, `K <= 9`;
- солнечная плотность потока: `1361 Вт/м²`;
- оптический КПД:
  - `1.00` при `K = 1`;
  - `0.99` при `K > 1`.

## Расчёт среднего cos(alpha)

Первоначальная аналитическая формула из ранней версии README признана некорректной и больше не используется.

В актуальной модели `cos(alpha)` рассчитывается по инженерным опорным значениям:

1. полиномиальная интерполяция 6-й степени по высоте на 7 опорных точках;
2. линейная интерполяция по степени концентрации `K`.

Подробности приведены в [`docs/specification.md`](docs/specification.md#6-средний-cosalpha).
