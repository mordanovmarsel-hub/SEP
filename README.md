# SEP

SEP — программа для поиска допустимых конфигураций солнечной энергетической установки космического аппарата с учётом ограничений по мощности, массе, площади, высоте орбиты, типу конструкции и степени концентрации.

## Актуальная спецификация

Утверждённая математическая и функциональная модель первой версии находится в:

- [`docs/specification.md`](docs/specification.md)

Именно этот документ является источником истины для реализации.

## Основные параметры MVP

- высота круговой орбиты: `400–3600 км`;
- степень концентрации: `K = 1..9`, шаг `1`;
- площадь СЭП: шаг перебора `0.1 м²`;
- конструкции:
  - сотопанель — `1.63 кг/м²`, `K <= 2.3`;
  - каркас — `1.69 кг/м²`, `K <= 9`;
- солнечная плотность потока: `1361 Вт/м²`;
- оптический КПД:
  - `1.00` при `K = 1`;
  - `0.99` при `K > 1`.

## Расчёт среднего cos(alpha)

Первоначальная аналитическая формула из ранней версии README признана некорректной и больше не используется.

В актуальной модели `cos(alpha)` рассчитывается по инженерным опорным значениям:

1. полиномиальная интерполяция 6-й степени по высоте на 7 опорных точках;
2. линейная интерполяция по степени концентрации `K`.

Таблица опорных данных, формулы и коэффициенты приведены в [`docs/specification.md`](docs/specification.md#6-средний-cosalpha).

## Результат

Программа должна выдавать все допустимые конфигурации, поддерживать фильтрацию/сортировку, выделение Парето-оптимальных решений и 3D-визуализацию результатов.
